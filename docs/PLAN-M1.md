## สัญญากลาง — `lib/types.ts`

เขียนโดย orchestrator ก่อนแตกงาน **ห้าม agent แก้** ถ้าสัญญาไม่พอให้รายงานกลับมา
อย่าแก้เอง เพราะโมดูลอื่นคอมไพล์กับไฟล์นี้อยู่

## เกณฑ์ผ่านของแต่ละโมดูล

**A — money**
- `bahtToSatang` รับได้ทั้ง number และ string (`"1,200"`, `"1200.50"`, `"1.2k"` ไม่รับ)
- ปฏิเสธค่าติดลบ, NaN, Infinity, ทศนิยมเกิน 2 ตำแหน่ง
- `distribute(total, weights, tieBreakIndex?)` — **ผลรวมต้องเท่ากับ total เป๊ะเสมอ**
  ไม่ว่าหารลงตัวหรือไม่ นี่คือ invariant ที่ต้องมี property test
- เศษที่เหลือกระจายแบบ largest-remainder; ถ้าเศษเท่ากันให้ `tieBreakIndex` ก่อน
  (คือคนจ่ายบิล) แล้วค่อยไล่ตาม index — ต้อง deterministic ไม่พึ่งลำดับ object key
- เคสที่ต้องมีเทสต์: `1200/7`, `1000/3`, `1/3` (เศษน้อยกว่าจำนวนคน),
  น้ำหนักไม่เท่ากัน `[2,1,1]`, คนเดียว, น้ำหนักเป็นทศนิยม

**B — split**
- 4 โหมด: `equal` `exact` `share` `itemized`
- surcharge กระจายตามสัดส่วน subtotal ของแต่ละคน ไม่ใช่หารเท่า
- **invariant กลาง: `Σ share.amountSatang === round(total × (1 + surchargePct/100))`**
  ต้องจริงทุกโหมด ทุกอินพุต — property test บังคับ
- `exact` ที่ยอดรวมไม่ตรง total ต้อง error ไม่ใช่เดาให้
- `itemized` ที่มีรายการซึ่งไม่มีใครกิน ต้อง error
- ผู้ร่วมหารซ้ำ, น้ำหนัก 0 หรือติดลบ, participants ว่าง → error ทั้งหมด

**C — debt**
- คิดจาก expense + settlement เป็น `PairDebt[]` ที่ค่าเป็นบวกเสมอ
- **หักกลบเฉพาะภายในคู่** — A↔B หักกัน แต่ห้ามยุบข้ามคนแบบ Splitwise
  เทสต์ที่ต้องมี: A ติด B, B ติด C, A ไม่ติด C → ผลลัพธ์ต้องมี 2 คู่ ไม่ใช่ 1
- settlement ที่ยังไม่ `confirmed` ไม่นับ
- expense ที่ `voided` ไม่นับ
- ยอดเท่ากันพอดีสองทาง → หายไปจากผลลัพธ์ ไม่ใช่คู่ที่มีค่า 0
- ผลลัพธ์เรียงแบบ deterministic

**D — parser/rules**
- จับได้: `+ ข้าว 1200`, `+ ข้าว 1200 กอล์ฟ เบียร์ ตูน`, `+ เหล้า 900 ... รวมฉัน`,
  `+ คอนโด 8000 กอล์ฟx2 เบียร์`, `#eventtag`, คำสั่ง `ยอด` `ทวง` `แก้` `เลิก`
- ตัวเลขไทย/คอมมา/ทศนิยม: `1,200`, `1200.50`, `๑๒๐๐`
- **ข้อความที่ไม่เข้ารูปแบบต้องคืน `unparsed` ไม่ใช่เดา** — เป็นอินพุตของ LLM ต่อ
- ข้อความที่ไม่ขึ้นต้นด้วย trigger คืน `null` (bot ไม่สนใจ ไม่เก็บ ไม่ส่ง LLM)
- ห้าม false positive: `+1` `+66812345678` `1200` เปล่าๆ ต้องไม่กลายเป็นบิล

## ขั้นตอน

1. orchestrator: `git init` + scaffold + `lib/types.ts` + commit แรก
2. spawn agent A, C, D พร้อมกัน — แต่ละตัว TDD ในไฟล์ตัวเอง
3. orchestrator ตรวจ: อ่านโค้ดจริง + รัน `npm test` เอง ไม่เชื่อรายงาน agent
4. spawn agent B หลัง A ผ่าน
5. ตรวจรอบสุดท้าย: เทสต์ทั้งหมดเขียว + `tsc --noEmit` ผ่าน + invariant ครบ
